This semester's pages

The SPAN 1001 site lists this semester's pages in sections, for example "Oral Final". Rename a section, change its dates, or add a page to it.

Edit this semester (new tab) See the SPAN 1001 site
  1. Open a section to change its name or dates, or add a new one at the bottom.
  2. To list a page, add it under Pages in this section with its name, file and a one-line description.
  3. Press Save. The site rebuilds its menus in about a minute.

The page file itself has to be on the site already; this list only adds it to the menu. Exams, answer keys, grades and student work never go on this site.

Start a new semester

This moves this semester's pages to the archive (they keep working) and starts an empty semester. Do it once, after final grades are in.

Start a new semester (new tab)
  1. Pick the season, year and class days.
  2. Turn on "Start it now?" and press Save.
  3. Wait about a minute. The old semester appears under past semesters on the site, and the new one is ready for pages.

D2L links point to the current semester. Update them in the new D2L course after you start the new semester.

Help

Who can edit

Only people Daniel invites can save changes. Anyone can read this help page, but the editor stays locked to everyone else.

Invite an editor (new tab)
  1. Type their email and send the invite. They don't need a GitHub account.
  2. Send them this page. It's all they need.
  3. To remove someone, open the same list and delete their email.

Invited editors can change content and upload files. Only Daniel can change how the forms work or who is invited.

Help

If something looks wrong

Most problems fix themselves with a refresh. If not, check these.

I saved, but the site hasn't changed.
Wait a minute, then refresh the page. Your browser may be showing an older copy; a private window always shows the newest.
I changed something by mistake.
Every save is kept. Tell Daniel what you changed and when; he can put the old version back in a minute.
The editor shows an error when I save.
It names the field to fix, for example a color code or an event code in the wrong format. Fix that field and save again.
